# Judith Website Design Rule

Before any website UI, page creation, or restyling task, read `STYLE_GUIDE.md` completely.

- Use it as the sole visual source of truth; it is based exclusively on the pasted Lifestyle Session HTML reference.
- Existing pages are content sources and restyling targets, not design references.
- Preserve accurate page-specific content, metadata, approved images, prices, packages, and destinations.
- Never invent facts, assets, image URLs, or links.
- Keep pages Hebrew RTL and preserve the standalone HTML plus Tailwind CDN architecture unless explicitly told otherwise.
- Do not add visual patterns absent from the guide without explicit user direction.
- Preserve unrelated user changes.
- Verify responsive layout, RTL flow, links, accessibility, and reduced motion before finishing.

Also follow `AGENTS.md`.
