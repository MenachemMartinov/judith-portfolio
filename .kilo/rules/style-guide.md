# Judith Website Design Rule

Before creating, redesigning, or editing any page or visual component, read `STYLE_GUIDE.md` completely.

- Treat the guide as the sole visual source of truth. It is based exclusively on the pasted Lifestyle Session HTML reference.
- Existing pages are content sources and future restyling targets, not design references.
- Preserve accurate page-specific content, metadata, approved images, prices, packages, and destinations.
- Never invent business facts, assets, image URLs, or links.
- Keep pages Hebrew RTL and preserve the standalone HTML plus Tailwind CDN architecture unless explicitly told otherwise.
- Do not introduce patterns absent from the guide without explicit user direction.
- Preserve unrelated user changes.
- Verify mobile and desktop layout, RTL flow, links, accessibility, and reduced motion before finishing.

Also follow the root `AGENTS.md` file.
