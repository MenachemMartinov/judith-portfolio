# Gemini Project Instructions

For every website UI, page creation, or restyling task, first read `STYLE_GUIDE.md` in full.

- `STYLE_GUIDE.md` is the sole visual source of truth and comes exclusively from the pasted Lifestyle Session HTML reference.
- Do not derive design rules from the existing HTML pages; use them only for accurate page-specific content and working destinations.
- Preserve approved content, metadata, images, prices, package details, and links unless the user asks to change them.
- Do not invent facts, assets, URLs, or service details.
- Keep pages Hebrew RTL and preserve the standalone HTML plus Tailwind CDN architecture unless explicitly told otherwise.
- Do not add visual patterns absent from the guide without explicit user direction.
- Preserve unrelated user changes.
- Validate the finished work against the guide at mobile and desktop widths, including RTL flow, links, accessibility, and reduced motion.

Also follow `AGENTS.md`.
