# Judith Website Review Rules

When reviewing UI or HTML changes, treat `STYLE_GUIDE.md` as the sole visual authority.

Flag changes that:

- derive visual rules from existing pages instead of the guide;
- introduce unapproved colors, fonts, components, navigation, or motion;
- copy service-specific facts between pages or invent facts, assets, URLs, or links;
- break Hebrew RTL behavior, responsive layout, accessibility, or reduced-motion support;
- overwrite unrelated user changes.
